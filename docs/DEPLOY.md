# Деплой: Vercel + Neon

Код уже подготовлен: `vercel.json` (регион `fra1`, Франкфурт), блокировка схемы совместима с пулером Neon,
фото ужимаются в браузере под лимит тела запроса Vercel (4,5 МБ). Схема БД создаётся сама при первом запросе.

> ⚠️ **152-ФЗ.** Vercel и Neon хранят данные за пределами РФ. Закон требует, чтобы персональные данные граждан РФ
> (имя, телефон, адрес) записывались и хранились в базе на территории России. Такой стенд подходит для демо и показа
> покупателю. Для боевого приёма заявок берите PostgreSQL и хостинг в РФ, например Yandex Cloud, Timeweb Cloud
> или Selectel. Код при этом не меняется: достаточно задать `DATABASE_URL`.

## 1. Вход в Vercel (делает владелец аккаунта)

```bash
npx vercel@66.6.0 login
```

Откроется браузер — войдите в свой аккаунт Vercel (можно через GitHub или e-mail).

## 2. Первый деплой и создание проекта

```bash
npx vercel@66.6.0 deploy
```

На вопросы отвечайте так: *Set up and deploy* → **Y**, scope — ваш, *Link to existing project* → **N**,
имя — например `vors`, каталог — `./`, *Modify settings* → **N**. Этот пробный деплой упадёт или покажет ошибку БД —
это нормально, базы ещё нет.

## 3. База Neon через Vercel (без копирования паролей)

Vercel → проект `vors` → **Storage** → **Create Database** → **Neon** → регион **Frankfurt (eu-central-1)** →
подключить к окружениям Production и Preview. Vercel сам добавит переменную `DATABASE_URL` (пулер Neon, SSL включён).

## 4. Переменные окружения

Vercel → проект → **Settings → Environment Variables** (Production):

| Имя | Значение |
|---|---|
| `OWNER_INITIAL_PASSWORD` | ваш пароль для первого входа в кабинет, ≥ 10 символов |
| `APP_URL` | `https://<ваш-проект>.vercel.app` (или свой домен) |

`DATABASE_URL` уже добавлен на шаге 3. `DATABASE_SSL` для Neon не нужен: SSL задан в строке подключения.

## 5. Боевой деплой

```bash
npx vercel@66.6.0 deploy --prod
```

## 6. После деплоя

1. Откройте `https://<домен>/admin`, войдите паролем из `OWNER_INITIAL_PASSWORD`, затем сразу смените его в разделе «Доступ».
2. В разделе «Компания» заполните город и реальные контакты, в разделе «Тарифы» — свои цены.
3. Проверка: `E2E_URL=https://<домен> E2E_PASSWORD=<пароль> npm run e2e`.
   Скрипт создаёт вымышленные заявки и удаляет их, временно меняет пароль и возвращает его обратно.
   Учтите лимит 12 заявок в час с одного IP: повторный прогон в течение часа упрётся в этот лимит.
4. Свой домен: Vercel → Settings → Domains. После подключения обновите `APP_URL` и задеплойте заново.

## Если что-то пошло не так

- **500 на всех страницах:** не задан `DATABASE_URL` или база не подключена к окружению Production.
- **«Пароль владельца не настроен»:** не задан `OWNER_INITIAL_PASSWORD` или он короче 10 символов.
- **Вход проходит, но сразу выбрасывает обратно:** `APP_URL` начинается с `http://` на HTTPS-домене. Нужен `https://`.
- Логи функций: Vercel → проект → **Logs**.
