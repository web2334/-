# Адаптация под другую компанию

Один экземпляр приложения = одна компания = одна база PostgreSQL. Чтобы запустить сайт для новой компании,
разверните копию с новой БД и своими переменными окружения.

## Меняется в кабинете, без программиста

| Раздел | Что настраивается |
|---|---|
| Тарифы | 9 базовых цен, минимальный заказ, % за загрязнения, % за вторую сторону матраса, доплата за город |
| Компания | название, описание, город, территория, часы, телефон, Telegram, WhatsApp, e-mail, юрлицо, акцентный цвет |
| Игра | выключена / без скидки / бонус; сумма, срок и минимум следующей чистки; погашение кодов |
| Персонажи | характер реплик (спокойный, весёлый, деловой), отключение лиц и рук, отключение реплик |
| Доступ | смена пароля, выход |

Новые цены действуют только для новых заявок: отправленные заявки хранят свои условия.

## Нужна правка исходников (обычно 0,5–2 дня разработчика)

| Что | Где | Комментарий |
|---|---|---|
| Логотип | `src/components/Icons.tsx` (`IconLogo`), `scripts/build-icons.mjs` | после правки: `ICON_ACCENT=#hex npm run icons` |
| PWA-иконки и OG-картинка | `scripts/build-icons.mjs` → `public/icons`, `public/og.png` | цвет берётся из `ICON_ACCENT` |
| Полная палитра (фон, текст, тёмная тема) | `src/app/globals.css`, блок `:root` | акцент меняется в кабинете |
| Тексты блоков главной | `src/app/page.tsx` | «Как это работает», подписи |
| Имена персонажей и реплики | `src/lib/phrases.ts` | |
| Цвета и пропорции 3D-мебели | `scripts/build-models.mjs` → `npm run models` | правка параметров, пересборка GLB |
| Новые 3D-модели | `public/models/*.glb` + `src/lib/catalog.ts` | имена узлов: `Furniture`, `Face`, `Eye_L/R`, `Arm_L/R`, `SpeechAnchor`, `EyeAnchor`; поверхности для игры — `extras.stain = true` |
| Политика обработки данных | `src/app/privacy/page.tsx` | **проверить с юристом** |
| Временные слоты | `src/lib/order-schema.ts` (`TIME_SLOTS`) | |

### Правка моделей в Blender

```bash
npm run models                          # пересобрать исходные GLB в models-src/
blender --background --python scripts/blender/import_models.py -- models-src assets/vors-models.blend
```

Скрипт собирает все модели в один `.blend` (каждая — своя коллекция, анимации сохраняются).
После правок экспортируйте glTF (.glb) в `models-src/` и выполните `node scripts/optimize-models.mjs`.

## Оценивается отдельно (не входит в MVP)

| Доработка | Примерный объём |
|---|---|
| Новая категория услуг (например, ковры): каталог, цены, модель, формула | 2–4 дня |
| Онлайн-оплата или предоплата (ЮKassa, CloudPayments): договор, чеки 54-ФЗ, вебхуки, возвраты | 4–7 дней + договор с эквайером |
| Расписание мастеров и выбор свободного слота | 5–10 дней |
| Несколько сотрудников, роли и права | 3–5 дней |
| Уведомления владельцу о новой заявке (Telegram-бот, e-mail, SMS) | 1–2 дня + сервис отправки |
| Уведомления клиенту о смене статуса | 1–3 дня + SMS/мессенджер |
| Интеграция с CRM (amoCRM, Битрикс24) | 2–5 дней |
| Автоматическое погашение бонусов и защита игры от накрутки | 2–4 дня |
| Несколько компаний в одной установке (мультиарендность) | 7–15 дней |
| Хранение фото во внешнем объектном хранилище (S3) | 1–2 дня |

## Регулярные расходы

| Статья | Ориентир | Комментарий |
|---|---|---|
| Хостинг Node.js | 0–2000 ₽/мес | бесплатные тарифы есть у Vercel (хостинг серверов за рубежом) |
| PostgreSQL | 0–1500 ₽/мес | для 152-ФЗ персональные данные граждан РФ лучше хранить в РФ (Yandex Cloud, Timeweb, Selectel) |
| Домен | 200–1500 ₽/год | |
| SSL-сертификат | 0 ₽ | обычно выдаётся платформой |
| Нейросети, Figma, Blender | 0 ₽ | после передачи сайт работает без них: реплики заранее написаны, модели лежат в GLB |

Фото хранятся в PostgreSQL (≈ 100–300 КБ на фото после сжатия). При 300 заявках в месяц с тремя фото это
≈ 100–250 МБ в месяц; когда база заметно вырастет, переносите фото в S3 (см. доработки).
